# Casa Maiorino

Esse é o site que fiz para a Casa Maiorino, o restaurante do meu tio aqui no Porto. É um espaço de sanduíches, cachorros-quentes e happy hour, com opções veganas também.

Fiz o site com ajuda de uma IA. Eu ia dizendo o que queria, mandando as fotos e os dados reais do lugar, e a gente foi ajustando até ficar do jeito que eu imaginava.

## O que tem no site

- **Início**: apresentação do restaurante, com a logo e atalhos para as outras páginas
- **Sobre**: um pouco da história da casa
- **Cardápio**: os lanches, com fotos em carrossel
- **Bebidas**: a carta de bebidas
- **Ambiente**: fotos do espaço (o salão já está, o resto vem em breve)
- **Visite-nos**: horários, morada, telefone e o mapa do Google

O visual veio da logo deles, que é preta e branca listrada. Também deixei tudo funcionando bem no celular, porque a maioria das pessoas vai abrir por lá.

## Como rodar

É só HTML, CSS e JavaScript, não precisa instalar nada.

1. Baixe ou clone o repositório
2. Abra a pasta no VS Code
3. Clique com o botão direito no `index.html` e escolha **Open with Live Server**

Ou então abra o `index.html` direto no navegador.
